# 課程內容及建議年齡 UI：2026-10-16

Stage A 新增「課程 → 指定課程 → 一般 → 課程內容」。管理員可以輸入雙語介紹及可選建議年齡，核對、返回修改、取消及原位返回；老師只讀授權課程，學生沒有管理表單。原有時間安排、費用及教材保留。

## 來源及採用理由

- 原 PDF 第 1 頁、Notion 快照 W-02 支持課程介紹及適齡資料。研究者重看 PDF 第 1／9 頁，SHA-256 不變；本片沒有重讀最新線上 Notion。
- 建議年齡是展示資料，支援 2.5、零、單邊及空值；不把目前示例 3–18 歲鎖成永久門檻，不推導報名資格。
- 第 9 頁圈出的每堂時長／月數屬費用；組合成分及實際排課另有時長。本片不新增會蓋過這些來源的單一課程時長。
- 空資料用一行自然提示，避免擠走日常排課；查看及編輯分開。公開讀取只接受明確提供的公開內容，目前正式公開服務沒有這些欄位，不從私有草稿或舊靜態課程補值。
- 此項是 PDF／Notion 的 Beamal 延伸；沒有冒稱新增介紹流程與 SchoolTracs 逐步相同。
