## 使用者效果與範圍

學生「我的課程」每個正式已啟用課次提供「查看訂單」。沿用目前授權的 student session / student / order ID，從服務重新取得訂單，核對唯一的 Course + schedule ID + sequence 後才開啟。同張原單可對應多堂，關閉仍返回剛才那一堂，保留捲動位置及鍵盤焦點。錯誤或載入中的課堂不提供猜配入口。

原單保存下單時的課堂及收費快照；現在時間表改期後日期可不同。介面已標明下單安排，不借現在 Fee 重算、不冒稱已知剩餘額度。新增入口沒有寫入報名、付款、出席、課包或帳戶資料。
