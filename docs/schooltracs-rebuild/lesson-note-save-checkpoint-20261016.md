# 指定課次的內部備忘：真正保存

只完成課程／時間表內一條可保存、修改、清空、重讀及返回的單堂備忘流程。這不是整個 Course／Timetable 或 Ultimate Goal 完成的聲明；其他模組保持暫停。

## 使用效果與來源

從課程的確切課次或時間表課堂詳情開啟備忘，先讀共用資料，再輸入／核對／儲存。成功回到同一堂、同一入口；取消及返回保留合理位置。備忘不要求該堂已有付款學生，亦不改學生個別備註、整期排課 remark、學生可見 moreInfo、出席、名額、付款或待辦。

Notion 現有快照 §17.2.4、TM-02／EX-24 確認日期或單堂純文字內部備忘，學生／家長不可見。PDF 第 3 頁的學生行 Remark 不冒充此來源。這是 Beamal 的已確認延伸，沒有把沒有觀察到的 SchoolTracs 功能稱為本輪動態對照完成。具體來源與取捨見 [source-contract.md](evidence/lesson-note-save-20261016/source-contract.md)。

最低權限映射是工程選擇：Admin 及目前實際負責該堂的老師可寫；其他只獲閱讀權的老師只讀。日期備忘的正式共享範圍未定，本片保持原草稿／核對，不啟用日期保存。已有單堂備忘可以清空內容，但版本及修改歷史保留，不刪除歷史。

## 保存與失敗處理

- 使用固定 schedule ID＋課次，獨立於課堂的日期／名稱。改期仍屬同一課次；舊課堂版本不能覆寫新來源，取消／不再授權後不可存。
- 備忘版本獨立管理；成功讀取且無記錄，才是已知空白版本 0。首次空白拒絕，未知／載入失敗不假裝「沒有備忘」。原文、換行及明確清空分清。
- 防重按、同一次安全重試、兩人版本衝突、操作歷史及失敗回滾。等候請求內容後、重送回放前及真正保存內重新核對權限。遲到、錯來源或換身份回覆不顯示假成功。
- 讀取中斷時，已有授權內容的本機草稿可繼續寫；核對／儲存停用。恢復後保留文字、焦點、選取及捲動。首次讀取未知仍不提供假空表單；撤銷寫權顯示真正只讀內容。
