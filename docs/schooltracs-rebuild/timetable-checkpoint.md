# 共用課程＋時間表保存及中期修正檢查點

日期：2026-10-14。這是本機 `test` 分支的功能切片，並非 Courses／Timetable 整頁或完整 Goal 驗收通過；未部署至真實業務。

## 已完成的行為

- 排課使用共用資料庫內的課程 ID。課程詳情及日／週／月／列表讀取同一份排課資料，不再把舊的本機示範班別混入共用時間表。
- 管理員可新增／修改／刪除整套重複排課，並撤銷刪除；老師可讀但不能修改。修改保留原 ID；服務確認成功後才關表單，失敗保留輸入，保存中阻止重複操作。
- 伺服器檢查登入、角色、版本、來源及重試識別。多人同時改同一筆時拒絕舊版本；稽核紀錄、資料及重試結果一起成功或一起取消。
- 背景更新先核對當前身份；同一身份刷新不清草稿，帳戶／角色改變時清空舊排課與表單。已接受新身份後，延遲舊回覆不能重填私人資料。
- 已核對 Mon＋Wed、Yes、四次的重複日期為 2026-10-14／19／21／26；其他未研究規則仍依 [來源紀錄](research-timetable.md) 的邊界處理。
