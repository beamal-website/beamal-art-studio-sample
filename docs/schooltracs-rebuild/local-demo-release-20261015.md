- 全新程式匯出到含空格的獨立資料夾，沒有 `.env`、資料庫、`node_modules` 或 `dist`；實跑根目錄 `npm start -- --no-open --port 0`，完成真正套件安裝、build、建示例資料及 HTTP 啟動。
