本片屬 Goal 階段 A 的主要任務 UI 修正，沿用已接通的共用 Course／Fee 保存；不是全系統完成、付款或規模驗收。上一個 Goal 回合重新核對了本機人物／家庭資料及 25 項相關測試，本片承接已證實的成功返回問題，不重新生成師生資料。

## 問題、採用理由與結果

- 從 Deleted／不相符搜尋、分類或程度新增課程，成功後可能看不到新課程；費用亦可被舊搜尋及 Single／Multiple 條件隱藏。現在從已接受的確切 ID 找最新資料，只解除不相容條件，保留相容搜尋、分類、程度與排序，再聚焦及顯示該筆紀錄。
- 成功返回不重播舊 Create 入口的捲動位置；取消仍返回原入口，保留原篩選與閱讀位置。從指定課程新增費用，留在同一課程，不改不相關的全局費用篩選。
- 同一費用可以出現在多個課程列。每個費用入口額外帶來源課程 ID，成功後返回同一個 `Fee + Course` 出現位置；若已解除該課程關聯，返回該課程的新增費用／課程入口，不跳去其他課程的同一費用。
- 真正 390px GUI 發現背景資料更新會重建清單並丟失剛儲存紀錄的焦點。背景重畫現在只恢復仍存在且可用的確切 Course／Fee 按鈕，保留位置；已移除、停用或換身份時，不選其他紀錄作替代。
- 導航會關閉課程建立／基本資料表單並使舊工作失效；遲到的舊回覆不把用戶拉回舊頁。包含沒有課型支援的舊服務路徑。
- 真正手機表單發現重複課名錯誤在捲動範圍外。建立課程的輸入／服務錯誤、費用課程選擇／服務錯誤現在聚焦並捲到提示；保留輸入、操作識別碼與取消返回。沒有新增收費或報名政策。
- 768px 英文畫面發現分類過窄及 Follows term 表頭擠壓；手機／平板課程篩選改為等寬兩欄，表頭在自己的欄內換行，整個闊表格仍只在其區域橫捲。
