# 教材附件切片驗收（2026-10-14）

此文件記錄 Courses／Fees 同頁的第三個切片。完整教材及整頁仍未通過；Goal 保持進行中。

## 參考證據與 Beamal 決定

SchoolTracs 本輪可確認十種格式提示、多檔輸入屬性及 50MB 提示，以及 Visible 關閉時保留 Download 勾選、取消後重設的草稿行為。没有上載或保存原系統教材；詳細限制見 `research-courses-fees.md` 第三切片。

Beamal 明確採用：每檔最多 50,000,000 bytes、每份教材最多 20 個附件；選檔先作草稿，儲存時依序上載，再一起保存教材及附件關係。格式提示本身不能證明檔案有效，服務會核對格式和基本結構；此檢查不是完整解碼或防毒掃描。隱藏教材儲存時下載政策仍為 false，原系統保存後的行為未查證。

## 保存、重試及私人資料

- 每檔穩定操作識別與教材操作識別，在回覆遺失重試時避免重複建立。100% 傳輸進度仍等待服务確認，不直接當作成功。
- 停止／失敗保留其他欄位和已完成的上載結果。修改與附件關係在同一資料庫交易保存；版本衝突保留草稿，不覆蓋其他人的新版本。
- 暫存檔限原上載者及同課程使用，未綁定暫存檔在 24 小時後清理。曾綁定而移除的原始檔保留作未來歷史／還原，目前不自動刪除；移除後的舊網址不可閱讀。
- 原始檔存於私密資料夾，權限及 HEAD／Range／下載每次由服務核對。學生另須課程教材授權與 Visible；專用下載網址另核對 Download。老師可唯讀。
- 備份須同時包括 SQLite 資料庫及旁邊附件資料夾；不可把原始檔、帳戶資料或資料庫提交到 Git。

## 獨立服務及流程檢查

涵蓋十種實際格式、大小邊界、未知／其他上載者／跨課程檔案、取消與重試、保存回覆遺失、修改衝突、原子回滾、重開資料庫、學生角色／授權／下載、移除舊網址、串流中斷、HEAD／範圍讀取及私密目錄隔離。前端另驗證草稿保留、順序進度、上載停止、錯誤重試、失效身份不能解鎖新工作及傳輸中固定操作。

獨立審查找到並修正：合法帶較大前置 atom 的 MP4 被拒；檔案串流雙重關閉造成間歇讀取失敗；每筆教材逐次查詢附件。修正後隔離重測 1,000 次連續與 4,000 次並行 GET／HEAD／範圍讀取均無失敗或重複關閉。批次查詢在 100／1,000／5,000 筆教材為 4／5／9 次；5,000 筆隔離直接讀取中位數約 193→25ms、HTTP 約 275→53ms。這些是服務資料，不代表實際瀏覽器大量資料操作已通過。

此切片修正後的整合測試及打包在檢查點記錄；不能把控制器測試通過當作實際 PDF 已顯示。PDF 閱讀頁使用本機 PDF.js、CMap 字碼及標準字型，不使用外部 CDN；真正 CID 中文 PDF 程式測試已讀出「繁體中文」，實際中文畫面仍待補。開發預覽的私密資料保護亦以虛構資料實測：`.data`、SQLite／附件及原有環境檔限制經一般與 `/@fs` 路徑均拒絕，公開檔案正常。
