# 指定學生、指定課次的出席與備註保存

本片只推進使用者最新指定的課程／時間表及直接相關流程。完整兩個模組、其餘主要功能及 Ultimate Goal 仍未完成。

## 實際效果

- 管理員或目前負責老師，可由課程／時間表的確切課次學生名冊，登記出席、遲到、缺席、請假、病假或其他；核對後真實保存，再返回同一學生與原課次。
- 備註、四種彩色貼紙及內部時間表顯示開關，保存於該學生該次課堂。只寫備註可以保留「未登記」，不強迫選出席。未有舊資料保留未知，不補造歷史。
- 顯示開關允許內部時間表投影；觀看者的「學生備註」偏好仍控制文字。關閉顯示後，時間表不投影該備註或貼紙。學生端只讀授權課節及出席結果，沒有內部備註、貼紙或修改入口。
- 操作沒有扣堂、扣分鐘、收款、釋放名額或改變全班出席。這些不同業務行為沒有被假裝完成。

## 保存、權限與恢復

既有共用資料服務新增指定 student-session PATCH；每次核對當前老師、確切已付款訂單及學生、有效課次與版本。只獲其他老師課堂閱讀權，不代表可寫出席。等待表單資料後及重試回放前重新核權，角色／來源改變不能借舊成功回覆越權。

單次請求有穩定防重送識別、版本衝突及原子操作記錄。失敗保留輸入；結果不確定時同一次請求可安全重試。遲到或錯人回覆、換身份、導航及較新版本不覆寫目前資料。真正來源改版明示重新開啟核對，不再顯示無法遵循的普通重試指示。

舊資料庫只安全新增五欄；原用戶 42 表的舊欄位及數量比對不變，原七課節的新欄位均為初始版本／未知。隔離 GUI 庫只有出席記錄、對應審計、防重送及登入會話改動。兩個服務已用原資料庫重新啟動，沒有重新種資料或重設帳戶。
