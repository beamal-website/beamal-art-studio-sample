## Beamal 的明確決定

這些限制沒有原系統保存證據，應視作本次產品／技術決定而非原系統規則：名稱去頭尾空白、最多 200 字；說明最多 10,000 字；最多 20 條影片連結；表單網址最多 2,048 字，服務最多 4,096 字。重複網址在前端合併，服務亦去重。老師唯讀、學生獨立授權及不可自行更改擁有人，也是目前 Beamal 的權限安排。

學生授權資料已在共用資料庫中，但目前沒有對外授權管理入口；隔離 HTTP 驗收使用內部種子建立虛構授權。正式報名／課節整合仍未完成，不能把此測試入口當作使用者流程。

## 服務入口及後續依賴

- `GET /api/courses/:id/materials`、`GET /api/materials/:id`：依登入角色和教材權限讀取。
- `POST /api/courses/:id/materials`：管理員新增，同一操作識別碼重試取得原結果。
- `PATCH /api/materials/:id`：管理員按凍結版本修改。
- `GET /api/catalog?since=revision`：首次回課程基本資料、關聯費用 ID 及一份費用清單；未改動時只回版本確認。前端還原原有列表資料，不在背景重建正在輸入的表單。

課堂分享、附件上載／預覽／下載、刪除／還原及學生端仍待接續。附件和課堂欄位暫停用並顯示未提供原因，非空附件／課堂資料會被服務拒絕，避免表面成功卻沒有保存。下載設定目前只是政策資料，尚無檔案下載端點。
