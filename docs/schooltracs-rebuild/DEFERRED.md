# 已略過的次要功能與仍重要的待辦

依使用者最新要求，先集中課程與時間表的關聯主流程，再接產品、學生、會計、報告及員工的主要功能，較次要且複雜的功能先不做。此清單隨實際研究更新，最終交付必須向使用者列出；略過不等於功能已通過。

| 功能 | 分類與理由 | 對使用的影響 | 本次處理 |
| --- | --- | --- | --- |
| SchoolTracs 訂閱、Book a Demo、外部支援／電話／電郵入口 | 參考服務自己的推廣與支援，非 Beamal 管理核心 | 不影響排課或共用業務資料 | 不重建這些外部服务流程；保留參考證據 |
| Timetable Print（獨立輸出連結，帶 `hideBar=print`） | 次要輸出流程；使用者已要求複雜 minor 先略過，原系統列印效果未實測 | 不影響時間表查詢、共用排課新增／修改及保存；暫無專用列印版 | 本輪先略過，保留 [時間表研究](research-timetable.md) 的直接觀察及未確認範圍 |
| 教材／PDF 進階相容性、密碼 PDF／互動表單、少見影音編碼 | 次要且複雜；使用者要求先略過本題 | 基本上載及已驗證 PDF 可使用；其他格式不保證可預覽 | 保留已完成基礎，不再延伸；中文實際畫面驗收尚待補 |
| 教材課節分享、刪除／還原及原系統學生端補查 | 目前不是指定優先頁，未全部研究 | 尚未有完整課節教材流程 | 保留待辦，並非將所有教材功能判為不重要 |

其他頁面的外部跳轉、下載／匯出或特殊整合，須先判斷是否影響指定主要操作，再列入略過清單；目前未觀察到的功能不臆造為已略過。

**仍重要，不能列作 minor：** 課程與時間表的共用關聯（同一課程 ID、同一套排課資料）、真正共用保存、角色權限與跨分頁身份清理、主要新增／修改／刪除、排課重複規則、學生與課程關係、會計數字正確及核心報表。課程／時間表切片會接續解決共用排課及身份範圍問題。
