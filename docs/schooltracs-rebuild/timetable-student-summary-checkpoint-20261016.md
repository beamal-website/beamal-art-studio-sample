# 課表學生摘要與名冊出席狀態 — 2026-10-16

本片延續全 UI 優先階段，處理課程／時間表的查看路徑。整個 Ultimate Goal 仍未完成。

## 來源、問題與結果

依客戶 PDF 第 3 頁、既有原稿／Notion 對照及 Notion 2026-10-14 主文快照 §6.1，名冊須能分辨逐學生的六種出席狀態；學生年齡、課表學生顯示沿用現有個人設定。本片沒有重新取得最新線上 Notion，也沒有把新的顯示方式冒稱為 SchoolTracs 已觀察的逐字行為。

0c3a929 基線中，已存在獲授權的批次學生資料，但卡片透過沒有傳課次的名冊快取讀取，姓名沒有顯示，人數固定為「—」。名冊則只顯示 Attendance 操作，沒有直接呈現 canonical attendance。獨立驗收保留原基線，三項期望行為真正失敗；Root 的四組整合測試亦先失敗，修正後通過。

現在：

- 正式課堂卡片讀取現有批次資料；依同一排課 ID、固定課次及有效日期對應，毋須為每張卡另讀一次名冊。
- 以學生 ID 分辨同名學生；已加入人數來自已付款課節。明確空名單顯示 0；尚未載入、失敗、缺課次／日期或身份失效維持未知，不能偽造 0。
- 最多列三個學生姓名，再顯示其餘人數；完整名冊仍由整張卡片原入口打開。長文字保留完整 title，並沿用卡片既有單行顯示，沒有增加卡片內巢狀按鈕。
- Students 顯示設定同時控制姓名及人數；Age 獨立控制年齡。年齡只接受同一課堂日期的有效年／月資料，沒有借舊瀏覽器 Profile、生日或家長資料補值；英文單複數亦正確。
- 名冊直接顯示 Present／Late／Absent／Leave／Sick／Other；明確 unmarked 為「未登記」，缺失或未知狀態為「未提供」。標籤有文字，並非只靠顏色。
- 原有指定學生課次的 Attendance、補堂、訂單及學生查看入口保留。新出席標籤旁按鈕另起一行，英文不拆字，觸控高度至少 44px。

## 實際畫面與返回

Root 使用隔離本機服務的真實既有資料，從側欄 Timetable → 每日 → 2026-10-23 → Leo 的創意繪畫第 2 堂：卡片顯示 Chloe、人數 1，Age 開啟時為 9 years 6 months；名冊同為 Chloe，canonical 狀態「未登記」。沒有把 300 份名冊當成 300 人已付費。
