## 具體修正與安全界線

- 產品詳細、建立／修改、核對及庫存表單使用同一個有固定標題／底部操作、內文可捲動的外框。原 Beamal 圖片與中英文保留，刪去沒有作用的產品副標題。
- 產品與庫存最後保存停用，旁邊以自然提示交代尚未開放。移除舊畫面副本的 Stock preview updated，避免源資料仍為0卻宣稱更新；核對頁分開原有庫存與擬調整結果。
- 金額最多兩位小數，要求可準確表示；不能把90071992547409.91核對成另一個數。0.29、0.00及.5仍有效。這是技術精度保護，不是新增產品商業價格上限。
- 庫存只接受安全正整數加減，不能減過現有數量，未知庫存不可調整；不引入入貨單、轉倉、預留或退款演算法。
- 可選 productsContext 是同步讀取邊界。明確 empty／loading／error／unavailable 不回退四件介面示例；來源一旦指定後消失亦不回退。相同身份的來源失敗保留原文並停用核對；選中紀錄改價等變更鎖住舊草稿，刪除／重複／換身份／離頁清掉舊私人視窗。這不是已接通 Product API 或真正非同步網絡競態驗收。
- Shared Admin 才能開維護視窗，Teacher／Student 偽造動作亦拒絕；沒有擴大真 API 權限。
- 背景來源更新不重建中文組字中的表單。原生瀏覽器實測另發現重畫時 focusout 收走舊控制項，清掉金額錯誤；先補失敗回歸，再加受控重畫保護、背景收草稿保留錯誤、真正修改才清錯。舊測試未覆蓋此生命週期，沒有用原綠燈替代實測。
